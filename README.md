# Punto_de_Venta_Cuatro_Semestre
Proyecto final de la materia Taller de Base de Datos. Desarrollé un sistema de punto de venta (POS) de extremo a extremo utilizando Java, implementando la interfaz gráfica con las librerías AWT y Swing. Aunque inicialmente se planteó utilizar SQL Server para la gestión de datos, realicé la migración e implementación final en MySQL para optimizar los tiempos de entrega. El desarrollo se llevó a cabo utilizando herramientas de inteligencia artificial como apoyo para agilizar la programación.
